One file per tool

Each generator is a single HTML page. There's no server, database or account to set up.

Works offline

Once a page has loaded, it keeps working without an internet connection, so it's fine in a sim lab or the back of an ambulance.

Print or save as PDF

Print straight from the browser, or save a PDF to reuse the same patient in future scenarios.

For training use only

Everything these tools produce is fictional. It isn't a medical record, medical advice or a clinical decision tool, and must never be used for real patient care or documentation.

Doses, vital signs and legal form text are plausible training defaults. Review them against your program's standards and local protocols before using them in class.
